# Instrucciones del proyecto

Antes de analizar, modificar o crear código para javiergamezmartin.com, lee y aplica obligatoriamente el archivo `MANUAL_ESTILO_WEB.md` del repositorio.

El manual prevalece sobre cualquier sugerencia genérica de diseño o refactorización. Modifica únicamente los archivos estrictamente necesarios para cumplir la petición. No alteres navegación, cabecera, pie, colores, tipografías, textos, enlaces, imágenes, estructuras, scripts, datos ni recursos que no estén afectados de forma directa por la solicitud.

Reutiliza las variables y componentes existentes de `style.css`. No introduzcas CSS inline, colores nuevos, tipografías nuevas ni componentes visuales ajenos al manual. No hagas commits, pushes, despliegues, borrados ni cambios masivos sin autorización expresa.

Antes de finalizar, informa de los archivos tocados, los cambios realizados, los elementos expresamente preservados y las comprobaciones efectuadas en escritorio, móvil, enlaces y accesibilidad.
